    Edit the text

    Fix mistakes, move pictures, paste an image, or add headings. Press Apply to redraw the pages. Changes to the options in step 2 are applied the same way.

    Pictures found

    Click a picture to put it at the cursor. Paste an image into the editor to add your own. Delete its line to remove it.

    Editing cheat-sheet
    • A blank line starts a new paragraph.
    • # Title makes a heading.
    • [[IMG:img_1]] places picture 1; [[IMG:img_1|50]] makes it 50% wide.
    • Pasted pictures use the same marker; edit the number after | to resize them.
    • [[PAGEBREAK]] starts a new page.
